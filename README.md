# 摸鱼派 APP 客户端

摸鱼派 APP 客户端 flutter 版本，提供鱼派聊天室、社区、清风明月等基本功能。

# 前排提示

APP 仍在开发中，欢迎大家 PR，欢迎 star，欢迎提 issue

## 鱼派 APP 开发史

在该版本之前，一共三个 APP 客户端，三个版本独立存在。

- 2022.01.04 由 [@HereIsYui](https://github.com/HereIsYui) 开发的 uni-app 版本上线
- 2022.06.02 由 [@iwpz](https://github.com/iwpz) 开发的 flutter 第一个版本上线
- 2022.06.25 由 [@csfwff](https://github.com/csfwff) 开发的原生安卓版本上线

由于种种原因，以上版本都陆续停止了更新和维护(~~开发者太懒了~~)。于是在 2023.10.11 日，flutter v2 版本的 APP 计划被提出，

但是因各种原因(~~才不是懒~~)，该版本于 2024.07.04 停止开发。

2024.09.13，项目重新提上日程，并决定弃用之前的架构，重新开发 v3 版本，所以本次版本号直接从 3.0.0 开始。

~~预计 24 年年底发出第一个正式版本！~~ ~~什么？怎么已经 2025 年了？~~  
好吧，现在已经是 2026 年了。我们决定先不和年底死磕，当前目标是把 v3 的核心功能做稳：能聊天、能看帖、能发帖、能逛清风明月、能管理账号，也能少一点奇怪问题。正式版会在体验足够稳定后再发布。

## 产品待办清单

以下待办按产品体验、功能闭环和性能稳定性整理（截至 2026.05.28），用于后续迭代排期。

### P0：优先修复

- [x] 补齐聊天输入更多面板里的图片和拍摄发送能力，或在功能完成前先隐藏这两个入口，避免用户点击后无响应。
- [x] 通知中心增加点击跳转能力：评论、回复、@、关注、同城、系统通知应尽量跳到对应文章、评论、用户主页或相关页面。
- [x] 拆分聊天室设置页，把自动抢红包、扩展插件、聊天室屏蔽名单拆成二级页面，降低单页信息密度。
- [x] 完善登录体验：登录中禁用按钮、密码显隐、忘记密码入口、二步验证码失败提示和重试反馈。

### P1：体验增强

- [x] 帖子页增加搜索、分类或排序入口，例如最新回复、最新发布、热门、精华等，提高社区浏览效率。
- [x] 清风明月发布框增加发布中状态、失败重试、字数提示和更明显的发送反馈。
- [ ] 聊天室扩展插件增加内置模板，例如小尾巴、今日状态、自动图片说明，并在编辑器里提供变量示例。
- [ ] VIP 功能增加设置入口，支持查看会员状态，并在服务端接口明确后支持修改昵称颜色、粗体、下划线。
- [x] 统一列表空态和错误态：加载失败保留旧数据，显示重试按钮，并区分网络失败、解析失败和无数据。

### P2：性能和工程质量

- [ ] 首页四 Tab 预加载改为分级调度：聊天和我的优先加载，帖子和清风明月延迟或空闲加载，降低登录后弱网请求峰值。
- [ ] 增加真机性能验收记录：冷启动耗时、首页可交互耗时、聊天 10 分钟内存峰值、图片缓存占用和返回首页后的回落情况。
- [ ] 建立统一视觉 token：卡片圆角、按钮高度、表单高度、边框粗细和页面间距，逐步替换旧页面里的零散样式。
- [ ] 梳理静默 `catch` 分支，把关键网络失败接入统一错误文案和可重试交互。
- [ ] 升级 Android Gradle/Kotlin 构建链，消除当前 Flutter 构建提示的未来兼容警告。
