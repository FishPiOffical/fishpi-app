## 操作步骤

1. 使用 profile 模式安装并运行：

   ```bash
   flutter run --profile
   ```

2. 完全杀掉 App 后冷启动，记录日志中的：
   - `性能标记[splash_visible]`
   - `性能验收[启动]`

3. 进入聊天室并停留 10 分钟，期间执行：
   - 上滑加载历史消息
   - 打开表情面板
   - 打开 5 张以上聊天图片
   - 播放 2 首音乐或语音消息

4. 记录 App 日志里的内存快照：
   - `内存快照[聊天首屏历史]`
   - `内存快照[聊天分页历史]`
   - `内存快照[聊天页关闭前]`

5. 使用 DevTools Memory 或 Android Studio Profiler 记录 Dart heap、external memory 和整体 RSS 峰值。

6. 从聊天室返回首页，等待 30 秒，再记录一次内存回落情况。
